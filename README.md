# Testimonial Showcase Application

A premium, modern, and highly interactive web application designed to collect, manage, and display customer testimonials. This project features stunning design, sleek animations, responsive layouts, and user-friendly interfaces to showcase social proof in the best possible light.

## 🚀 Features

- **Dynamic Testimonial Wall**: Grid and carousel layouts to showcase client feedback.
- **Filtering & Searching**: Easily sort or search testimonials by rating, industry, or keywords.
- **Interactive Submission Form**: Clean and intuitive modal/form for users to leave their feedback and ratings.
- **Responsive & Premium UI**: Designed with glassmorphism, fluid micro-interactions, dark mode support, and responsive layouts.

## 🛠️ Tech Stack

- **Frontend Framework**: React / Vite
- **Styling**: Vanilla CSS (Premium design tokens, custom properties, modern animations)
- **Icons**: Lucide React / SVG icons
- **State Management**: React Context / Hooks

## 📦 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Yami066/NOTNAMED.git
   cd testimonial
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
