# Yami — High-Conversion Digital Agency Website

A premium, modern, and highly interactive digital agency website called **Yami**, built to showcase professional web development services, showcase a curated portfolio, and establish solid trust with potential clients.

This project uses **Next.js** (App Router), **Tailwind CSS v4** (with `@theme` CSS inline tokens), and **next-themes** for seamless Dark Mode integration (warm cream canvas in light mode and sleek charcoal canvas in dark mode).

---

## 🎨 Visual Identity & Design System

The visual style is inspired by modern developer-focused editorial brands:
- **Light Canvas**: A warm cream page floor (`#f7f7f4`) with near-black ink (`#26251e`) for body/display text.
- **Dark Canvas**: Inverted deep charcoal canvas (`#141414`) with custom grey surfaces (`#1a1a1a`) and crisp white text.
- **Primary Brand Voltage**: Bold orange (`#f54e00` in light mode, `#ff6a2a` in dark mode) used strictly for CTA buttons, interactive elements, and highlight badges.
- **Typography**: Clean, magazine-like typography using **Inter** as the sans font family (with negative letter-spacing for headlines) and **JetBrains Mono** for developer aesthetics and code blocks.
- **Borders & Shadows**: Sharp, modern borders (`1px`) with zero drop shadows for a flat, editorial layout.

---

## 🚀 Key Features

1. **Interactive Navigation**: Dynamic header featuring smooth transitions, navigation links, theme toggle button, and a prominent CTA.
2. **Hero Section**: magazine-style headline with negative tracking, sub-headline, and an interactive developer IDE mockup (split into editable code and live preview panels).
3. **Portfolio Grid**: Visually stunning project showcase displaying real-world application builds (e.g., NovaPay, Bloom, Meridian) with industry tag badges, tech stacks, and live mock links.
4. **Social Proof & Testimonials**: Dynamic grid of five realistic testimonials highlighting positive metrics and outcomes (e.g., *68% lead increase*, *42% bounce drop*).
5. **Contact Page**: Modern inline contact form featuring customizable services checkboxes, client info fields, sidebar cards, and client validation.
6. **Dark Mode Integration**: Full system and user dark/light preference support using `@next-themes` to avoid hydration flickering.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) (using CSS Variables and `@theme`)
- **Theme Provider**: [`next-themes`](https://www.npmjs.com/package/next-themes)
- **Icons**: [`lucide-react`](https://lucide.react.dev/)

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `yarn` / `pnpm`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Yami066/NOTNAMED.git
   cd testimonial
   ```

2. **Install all dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser to see the results.

4. **Build the production application:**
   ```bash
   npm run build
   ```
